# 00 — Brief

What this project is and why it exists: context for anyone working on it. The reasoning behind specific choices is in `05-decisions.md`.

## 1. What it is

A one-page portfolio for Ola Jin Myhre Nymoen: selected work in architecture and software, plus education and contact. Plain HTML, CSS and JavaScript, published with GitHub Pages at https://olajmn.github.io/portfolio/. The architecture work has its own site, linked from the Architecture Portfolio card.

## 2. Aim

Give a visitor an overview of the work and the interests behind it. The page states that aim in the About section.

## 3. What it is not

- Not a content management system: the sections, the project cards and the education list are written in `index.html`.
- Not a framework app: no build step and no package dependencies.
- Not the architecture portfolio. That site is a separate project.
