# projectCards

Behaviour on a project card in `index.html`.

- `carousel.js` — cross-fades the images in `[data-carousel]`. Reduced motion keeps the first image.
- `demoPassword.js` — fills each `.project-password` from its `data-password`. The password text stays in `index.html`.
- `projectCards.css` — the card, including the carousel's stacking and fade.
- `demoPassword.css` — the password field.

The principle's word for this folder is not settled. It is held by `src/components/` and holds the four files above.
